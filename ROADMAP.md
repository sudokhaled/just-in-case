# Roadmap

The complete outline of what this library will contain. Every topic has a fixed id and file path, so writers and translators can work in parallel without collisions.

**Status:** ✅ written · 📝 planned (help wanted: see [CONTRIBUTING.md](CONTRIBUTING.md))

**Priority:** ★ critical (saves lives in the first days) · ● important (needed within weeks) · ○ useful (long-term)

## Translations

The structure is ready: copy `content/en/` to `content/<code>/` (for example `ar`, `es`, `fr`, `hi`, `sw`, `zh`), then translate `categories.txt`, `strings.txt` and the articles. Critical (★) articles first. See [CONTRIBUTING.md](CONTRIBUTING.md#translating).

| Language | Status |
|---|---|
| English (`en`) | Source language |
| Arabic, Spanish, French, Hindi, Swahili, Chinese, Portuguese, Bengali, Russian, Indonesian, Urdu | 📝 Wanted |
